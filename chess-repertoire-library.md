# Chess Repertoire

Opening repertoire pages (one ```pgn``` block per variation/line) with
SM-2 spaced-repetition review — a "Chess: Ôn tập khai cuộc" (Repertoire
training) command that quizzes you move-by-move and schedules the next
review based on how well you did.

**Depends on 2 other plugs, installed first**:
[`chessnote-plug-core`](https://github.com/covuaduongsinh/chessnote-plug-core)
(repertoire-page detection) and
[`chessnote-plug-db`](https://github.com/covuaduongsinh/chessnote-plug-db)
(line storage + SM-2 review state).

Originally built as part of
[ChessNote](https://github.com/covuaduongsinh/chessnote), a chess-focused
SilverBullet fork.
